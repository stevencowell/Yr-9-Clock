# Year 9 Clock Guided Course

A complete, browser-based Industrial Technology Timber guided course for the Year 9 Clock project.

## Student pathway

- ten paired-week modules covering Weeks 1–20
- three substantial project-specific theory sections per module
- twelve contextual knowledge checks per module, with hints and immediate feedback
- four scaffolded written responses per module, with feedback prompts and appropriate response examples
- browser/device-local autosave and a downloadable module evidence PDF
- a progressive twelve-card project folio with local ZIP/JSON backup and restore

## Source authority

The supplied working drawing, assessment brief, teacher direction and actual school procedures control the project. The course does not add unverified dimensions, component schedules, machine settings or finishing directions. High-risk visuals show the supplied drawing, assessment requirements or an approved safety reference.

Visual provenance and intended use are recorded in [ASSET-SOURCES.md](ASSET-SOURCES.md).

## Hosting

This static site is designed for GitHub Pages from the repository root. Open `index.html` through a local web server for testing.
